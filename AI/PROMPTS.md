
# Uso de inteligencia artificial - NetCash

## 1. Objetivo

Se utilizó inteligencia artificial como herramienta de apoyo
y orientación técnica para la estructuración del proyecto,
la comprensión de la arquitectura Onion, la organización
de los componentes y el desarrollo e integración de las
funcionalidades del sistema.

## 2. Herramientas de inteligencia artificial

### Herramienta utilizada

- ChatGPT (OpenAI): orientación técnica, estructuración
  del proyecto, asistencia en el desarrollo y comprensión
  de los componentes del sistema.

- Claude (Anthropic): análisis de arquitectura de software
  y comprensión de estructuras de programación.

- Gemini (Google): consultas técnicas, análisis de
  información y comprensión de tecnologías.

- GitHub Copilot (GitHub): asistencia en programación,
  organización de código y buenas prácticas de desarrollo.

## 3. Áreas de orientación técnica

- Estructuración de la arquitectura Onion.
- Organización de las capas del backend.
- Diseño y relaciones de la base de datos.
- Comprensión de los mecanismos de autenticación.
- Organización de componentes del frontend.
- Integración entre Angular y .NET.
- Comprensión de las reglas de negocio.
- Configuración de Docker y PostgreSQL.
- Identificación y resolución de errores técnicos.
- Aplicación de buenas prácticas de desarrollo.

## 4. Prompts representativos

Las siguientes instrucciones representan las consultas
realizadas durante el proceso de desarrollo del proyecto.

### Prompt 01 - Arquitectura del sistema

¿Cómo estructurar un sistema de gestión de cajas utilizando
arquitectura Onion con .NET y PostgreSQL?

### Prompt 02 - Organización del backend

¿Cómo organizar las capas de dominio, aplicación,
infraestructura y presentación, considerando la separación
de responsabilidades?

### Prompt 03 - Base de datos

¿Cómo estructurar las entidades y relaciones de una base
de datos PostgreSQL mediante Entity Framework Core?

### Prompt 04 - Seguridad y autenticación

¿Cómo comprender e implementar mecanismos de autenticación
JWT/JWE, cifrado de información y control de acceso
basado en roles?

### Prompt 05 - Reglas de negocio

¿Cómo organizar las funcionalidades relacionadas con
la asignación de cajeros, administración de cajas,
gestión de turnos, contratos y pagos?

### Prompt 06 - Arquitectura del frontend

¿Cómo estructurar un proyecto Angular mediante componentes,
servicios, modelos, guards e interceptores?

### Prompt 07 - Integración del sistema

¿Cómo establecer la comunicación entre un frontend Angular
y una API REST desarrollada con ASP.NET Core?

### Prompt 08 - Diseño de interfaces

¿Cómo organizar interfaces reutilizables, responsivas
y funcionales para un sistema de gestión empresarial?

### Prompt 09 - Infraestructura y Docker

¿Cómo estructurar un entorno mediante Docker Compose
que permita integrar Angular, .NET y PostgreSQL?

### Prompt 10 - Resolución de problemas

¿Cómo identificar y solucionar errores relacionados con
la compilación, configuración y comunicación entre los
componentes del sistema?

### Prompt 11 - Buenas prácticas

¿Qué buenas prácticas de ingeniería de software se pueden
aplicar para mejorar la organización, seguridad,
mantenibilidad y escalabilidad del proyecto?

### Prompt 12 - Validación del sistema

¿Cómo organizar las pruebas funcionales para comprobar
la comunicación entre los componentes y el cumplimiento
de las reglas de negocio del sistema?

## 5. Aplicación de la asistencia técnica

La inteligencia artificial fue empleada como recurso
complementario para fortalecer la comprensión técnica,
orientar la toma de decisiones arquitectónicas y apoyar
el desarrollo e integración del proyecto.

Las orientaciones y el código proporcionados fueron
incorporados durante el proceso de desarrollo, realizando
pruebas manuales para verificar el funcionamiento de
los principales módulos del sistema.

## 6. Responsabilidad del desarrollo

La configuración del entorno, integración de componentes,
ejecución del sistema y validación funcional fueron
realizadas por el desarrollador responsable del proyecto.
